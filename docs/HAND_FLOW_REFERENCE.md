# 手牌流转参考：《杀戮尖塔》系列

更新日期：2026-09-22

## 可观察的动画原则

参考 Mega Crit 公开的《杀戮尖塔 2》[官方玩法预告](https://www.megacrit.com/news/2024-12-12-gameplay-trailer/)和实际游戏公开画面，可以提炼出以下不涉及源码的表现原则：

- 卡牌必须从可识别的来源出发，并落到可识别的目的地；抽牌堆、手牌和弃牌堆之间的关系由运动轨迹说明。
- 多张牌不会完全重叠移动，而是以很短的时间差连续出发。
- 飞行不是匀速直线：离开牌堆时略微抬升和放大，接近目的地时缩小并减速。
- 牌面只在应该对当前玩家公开时显示；从未知牌堆抽取时先显示牌背，到达手牌后再显示牌面。
- 弃牌动作保留牌面辨识时间，然后缩入弃牌堆；目的地会给出短促反馈。

本项目据此采用自己的参数、配色和轨迹，没有使用《杀戮尖塔 2》的代码或资产。

## 手牌已满时的规则

《杀戮尖塔》系列的常规最大手牌数是 10，但“抽牌”和“生成/返回手牌”需要分开理解。

### 常规抽牌

如果当前手牌只剩 `N` 个空位，而效果要求抽取多于 `N` 张牌：

1. 只抽取能够放入这 `N` 个空位的牌。
2. 手牌满后，剩余抽牌停止。
3. 没有实际抽出的牌继续留在抽牌堆，不会因为本次抽牌直接进入弃牌堆。
4. 玩家会收到“手牌已满”一类反馈。

社区规则资料也将其描述为手牌达到 10 张后中断继续抽牌：[手牌上限 FAQ](https://wikiwiki.jp/slaythespire/%E3%82%B2%E3%83%BC%E3%83%A0%E6%94%BB%E7%95%A5%E3%81%AEFAQ)。

### 生成、复制或返回手牌

如果效果不是从抽牌堆进行常规抽牌，而是生成卡牌、复制卡牌或把其他区域的牌加入手牌：

1. 仍然优先填满剩余手牌位置。
2. 超出手牌上限的卡牌进入弃牌堆。
3. 《杀戮尖塔 2》的 `Make It So` 规则明确记录了手牌满时，未能返回手牌的多余卡牌进入弃牌堆：[Make It So 规则](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2%3AMake_It_So)。

因此，“抽不到”和“加入手牌失败后弃掉”是两个不同结果。前者不移动牌，后者确实改变牌所在区域，并可能影响与弃牌相关的效果。

## 与本项目当前规则的差异

本项目的手牌上限是 8。当前所有进入手牌的卡牌统一经过 `resolve_hand_entry_for_player()`：位置不足时，卡牌会进入共享弃牌堆，包括从牌库抽取的牌。

本次修改保留了这条现有规则，只改善动画，原因是改变它会同时影响：

- 弃牌触发技能；
- 抽牌统计与牌库循环；
- 魅惑、复制和其他“加入手牌”效果；
- 已有关卡和牌组平衡。

如果后续决定完全采用《杀戮尖塔》的规则，应把“常规抽牌”与“生成/返回手牌”拆开验收：普通抽牌先按空位限制从牌库取牌，生成或返回手牌仍将溢出牌送入弃牌堆，并分别测试触发器、统计、洗牌和联网同步。
