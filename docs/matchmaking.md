# 排位赛与随机对战

从主菜单进入「联机对战 → 专用服务器」，选择「排位赛」或「随机对战」。

- 排位和随机均在匹配后进入出战准备页，选好卡组并准备。双方就绪后，提交的卡牌各合入公共牌池一次，由服务器洗牌，两人从同一牌库抽牌。每组至少要能提供一手开局牌。自制卡的规则会同步，自定义卡面采用本机已有素材。
- 排位初始积分 1000，优先匹配积分接近的对手。段位门槛依次为青铜 0、白银 900、黄金 1100、铂金 1300、钻石 1500、大师 1750。随机对战独立排队，无排位结算。
- 排位的战斗参数由 `PlayerData.DEFAULT_BATTLE_CONFIG` 统一提供，与标准战斗共用。两种匹配都可取消，沿用行动计时、重连和战绩页面。
- 排位由服务器按 Elo 计算基础分，再用玩家自己携带的卡组系数调整正数增量。单方放弃或重连超时按负处理。
- 已配对、房间尚未发出连接信息时，若一方取消，另一方保留原排队时间，继续等待对手。

## 卡组系数

用卡牌编辑器的强度估值减去该费用对应的预算，得到单卡强度差值。计算整组差值的均值和总体方差。均值接近 0 且方差小的卡组得分系数更高。600 至 1800 分之间，积分越高，强度偏离和方差的扣减越严格。乘数限制在 0.75 至 1.15，保留两位小数。选组时可预览，赛后加分时可查看实际系数。扣分保留基础 Elo 值。

## 运行服务

匹配复用现有专用服务器及其 UDP 端口范围。客户端与服务端使用同一版本的项目或对应导出包。Windows 包中，客户端直接运行 `Cardex.exe`，服务端运行：

```powershell
.\Cardex.exe --headless -- --server --lobby-port=4567 --port-start=5001 --port-end=5020
```

本机测试可在两个独立客户端的匹配页面打开「服务器设置」，填写 `127.0.0.1:4567`。专用服务器的端口配置沿用既有部署方式。

玩家资料绑定该安装使用的本机配置目录，`user://matchmaking_identity.pem` 是私钥。服务器保存的排位记录位于 `user://ranked_matches.jsonl`，`user://matchmaking/` 保存尚未收尾的对局文件。更新或迁移服务器时保留这两个位置。
